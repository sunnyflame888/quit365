# QUIT / 365 — 私人戒烟执行与记录系统 V1.0

手机优先、静态部署、离线优先、本地保存、无账号和外部分析脚本的个人戒烟管理工具。

## 快速开始

1. **最推荐：静态HTTPS托管。** 将整个 `quit365-v1` 文件夹的内容（包括 `index.html`、`src/`、`icons/`、`styles.css`、`manifest.webmanifest`、`sw.js`）上传到任何支持静态文件的HTTPS托管平台，如 Netlify Drop、Cloudflare Pages、GitHub Pages等。必须让 `index.html` 位于网站根目录（或对应子目录）；不需要服务器数据库、Node依赖或API Key。
2. 打开部署后的HTTPS网址，检查「今天」「每日记录」「戒烟进展」「治疗计划」「设置与数据」。
3. iPhone Safari：分享按钮 →「添加到主屏幕」。建议**首次录入前**就决定是否以主屏幕安装模式长期使用；不同浏览器与安装模式之间，本地数据未必自动共享。
4. 在「设置与数据」核对计划日期、服药时间，并且只有在医生或药师明确核对用药安全后，才勾选“已核对个人用药方案”。
5. 每天填写真实烟草数量/烟瘾/药物记录，睡前勾选“我已经核实并完成这一天的记录”。
6. **每周导出一次加密备份**，换手机、清理浏览器数据或重装PWA前必须备份，再在新设备通过设置页恢复。

## GitHub Pages 部署与使用

- 仓库：https://github.com/sunnyflame888/quit365
- 网站：https://sunnyflame888.github.io/quit365/
- 将原 `quit365-v1` 文件夹**内部文件**放在仓库根目录，`index.html`、`.nojekyll`、`sw.js` 与 `manifest.webmanifest` 同级。无需构建、数据库或运行时依赖。
- GitHub 仓库 → **Settings → Pages → Build and deployment**，Source 选择 **Deploy from a branch**，Branch 选择 **main**，目录选择 **/(root)**，点击 **Save**。等待 Pages 部署完成后访问上述网址。
- HTML、CSS、ES 模块、图标均保留相对路径；Manifest 的 `start_url` 为 `./index.html`、`scope` 为 `./`；`./sw.js` 默认控制 `/quit365/`。不要改成以 `/` 开头的站点根路径。
- 首次联网打开后等待 Service Worker 安装和缓存完成，再刷新一次。之后同一浏览器可离线使用已缓存页面；首次打开仍需联网。更新应用静态资产时应更新 `sw.js` 缓存版本并验证新版本。
- iPhone：使用 **Safari** 打开网站 → 底部（部分版本在菜单内）**分享** → **添加到主屏幕** → 如有“作为网页 App 打开”选项则开启 → **添加**。从主屏幕图标打开并首次联网加载。开始记录前先决定长期使用 Safari 还是主屏幕模式；两者存储可能不同。
- 数据只保存在当前设备浏览器中，不会随源码提交或跨设备同步。IndexedDB 按域名隔离，同一 `sunnyflame888.github.io` 域下的其他项目也应保持可信；不要在此域部署不可信脚本。
- 清理网站数据、删除主屏幕 App、隐私浏览及设备空间回收均可能导致数据丢失。建议每周加密备份；普通 JSON/CSV 未加密，保存在仓库外的私人位置。
- 公开仓库仅包含程序、静态素材、测试与文档；禁止提交真实日志、导出备份、密码或密钥。`.gitignore` 已忽略常见备份及密钥文件，但提交前仍应检查文件清单。


或使用任意静态HTTP服务。直接用 `file://` 打开 `index.html` 通常不受浏览器ES模块、Service Worker限制支持，**请用 HTTP / HTTPS**。PWA安装、Service Worker离线缓存、加密备份等能力应使用HTTPS（或localhost）。

## V1.0 已实现

- **今天**：日期驱动的12周阶段、当天处方参考剂量、服药记录、IQOS参考使用规则、自动里程碑。
- **每日记录**：任意已过去日期、IQOS/卷烟/其他烟草使用、药用尼古丁口香糖实际使用、最高渴求、出现次数、诱因、应对方式、睡眠、恶心、心情、早晚服药与备注。
- **进展**：严格区分“未填写”和“已确认零支”；基于已确认日志的连续无烟天数、累计无烟日、出现使用的日期、服药记录完成率、最近14天趋势、诱因频次。
- **Craving 急救**：10分钟可暂停计时器、行为应对流程及应对次数记录。
- **治疗计划**：标准说明书阶段、可选的准备期IQOS减量参考（不是处方）、12周里程碑、安全警示及官方资料链接。
- **设置**：可更新日期和服药展示时间、记录已获医生确认的维持期剂量调整、历史修订日志。
- **数据**：IndexedDB；不支持时退化到 localStorage。JSON完整备份/恢复、CSV导出、防表格公式注入、AES-GCM加密JSON备份、打印当前页面为PDF。
- **PWA**：Manifest、安装图标、静态资产离线缓存。首次加载需要联网；之后离线访问仍应依赖浏览器是否保留缓存。

## 重要边界

- **本软件不是医疗器械，也不能自行确定用药安全性**。伐尼克兰剂量默认取成人肾功能正常时的常规说明书参考：第1–3天0.5 mg每日1次；第4–7天0.5 mg每日2次；第8–84天1 mg每日2次。用户实际处方、肾功能、并用药物和不良反应必须经开药医生或药师核对。第84天之后不自动延长治疗。
- **10月22日启动、10月29日完全停用IQOS**是应用的初始日期设置，可在设置页修改。准备期减量数量是可选行为建议，不代表需要吸烟。完全停用后目标是0支；发生一次使用应如实记录并尽快恢复无烟计划。
- 药用尼古丁口香糖仅用于**实际使用记录**，程序不自动推荐使用或剂量。复吸风险、重度症状和医疗紧急情况需联系专业医疗人员。
- 网页自身**不主动发送系统推送通知**，请在手机提醒事项/日历中单独设定服药与复盘提醒。
- 本地数据不与ChatGPT自动同步，不与其他设备同步。要让我帮你复盘，请手动提供导出的CSV或你选择分享的摘要。
- **普通JSON/CSV/打印文件未加密**。只有「加密备份」使用 WebCrypto 的PBKDF2-SHA256（31万次）+ AES-256-GCM；丢失密码无法恢复，亦不能防护已解锁设备上的浏览器访问。
- 浏览器清理缓存/数据、私人模式、删除主屏幕网页及设备故障可能导致数据丢失。定期备份至可信任的位置。

## 用Codex继续维护（推荐提示词）

> 请阅读 `README.md` 和 `src/logic.js`，保留 QUIT / 365 的本地优先、无账号、隐私优先、处方安全边界与已有数据结构。每次修改先运行 `npm test`，不得把未填写日期当作无烟、不得自动根据烟瘾分数修改伐尼克兰剂量、不得擅自将健康数据上传服务器。若更改了离线资产，更新 `sw.js` 中的缓存版本并测试iPhone Safari/PWA行为。优先做小范围、可测试的增量修改。
